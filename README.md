# Aqua Language Support

Basic syntax highlighting for the Aqua programming language.

## Known Limitations

- Highlighting is regex-based (no semantic analysis yet).

## Contributing

- Follow the [Aqua programming language specification](https://github.com/aqua-aq/aqua-spec)
- Do not use AI for writing code. (Code reviews, ideas, suggestions etc do not count)
